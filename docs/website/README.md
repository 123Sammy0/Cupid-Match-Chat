# Cupid Match Chat prototype

Open `index.html` in a modern browser to use the local UI prototype.

It includes a Little Library masonry landing page, discreet private-entry button, local sign-up/login/logout flow, code-based conversation history, and a chat UI. Data is stored only in that browser's `localStorage` for prototype testing.

For the real private app, replace localStorage authentication/chat persistence with Supabase Auth, Postgres/Realtime, Storage, row-level security, and the approved admin controls. Add WebRTC for live audio/video calling.
